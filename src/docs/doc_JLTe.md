# Security Policy / Politique de sécurité

**english:**
If you discover a security vulnerability in UniStack, please report it by opening an
issue labeled `security` or by emailing security@unistack.org. Do not publicly disclose
the details until a fix is available. Always ensure you are running the latest release.

**french:**
Si vous découvrez une vulnérabilité de sécurité dans UniStack, veuillez la signaler
en ouvrant une issue étiquetée `security` ou en envoyant un courriel à security@unistack.org.
Ne divulguez pas les détails publiquement tant qu'une correction n'est pas disponible.
Assurez-vous toujours d'exécuter la dernière version.

---

## Supported Versions / Versions supportées

Only the latest major release is actively maintained. Security fixes may be backported
at the maintainers' discretion.
